# EnterpriseFlow AI Demo

[![CI](https://github.com/NgaseBupe/enterpriseflow-ai-demo/actions/workflows/ci.yml/badge.svg)](https://github.com/NgaseBupe/enterpriseflow-ai-demo/actions/workflows/ci.yml)

A focused demonstration of AI-assisted document intake. A reviewer uploads a customer purchase order, AI extracts the order details and line items, the system checks the arithmetic, and a human reviews, corrects and confirms the result. Every step is recorded in an audit trail.

The AI assists; it never accepts or rejects an order.

> **Status:** in development. See the [design document](docs/design-proposal.md) for the architecture and the implementation plan.

## Tech stack

Java 17 · Spring Boot 3.5 · MySQL · React 19 · TypeScript · Vite · Docker · GitHub Actions

## Disclaimer

This project is a demonstration and uses synthetic data only. It is not an order-management system and does not accept, reject or process orders.
